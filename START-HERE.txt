Taiga в Claude Code
===================

СТАВИТСЯ ОДИН РАЗ НА КОМПЬЮТЕР

  Не на каждый проект. Поставили — архив больше не нужен.
  Следующий проект подключается одной фразой в чате Claude Code:

     подключи эту папку к проекту <слаг>

  Распаковывать и устанавливать заново НЕ НУЖНО.


ЧТО ЗАПУСТИТЬ

  macOS    двойной щелчок по  setup-macos.command
  Windows  двойной щелчок по  setup-windows.cmd
  Linux    в терминале:       bash setup-linux.sh

Установщик сначала спросит, кто вы:

  1) МЕНЕДЖЕР — вести задачи: смотреть, создавать, двигать по доске,
     раскладывать техническое задание в эпики и истории.

  2) РАЗРАБОТЧИК — то же плюс дозорный: раз в час проверяет трекер,
     кладёт заготовки разбора в папки проектов и уведомляет.

Дальше пять шагов: проверка окружения, плагин, программа, вход в Taiga,
подключение первого проекта.

Пароль при вводе НЕ отображается — ни звёздочек, ни курсора.
Это нормально: печатайте вслепую и нажмите Enter.


ЕСЛИ macOS НЕ ДАЁТ ЗАПУСТИТЬ

  «Не удаётся открыть, так как разработчик не установлен» —
  правая кнопка по файлу -> «Открыть» -> в окне ещё раз «Открыть».


ЕСЛИ WINDOWS НЕ ДАЁТ ЗАПУСТИТЬ

  Запускайте setup-windows.cmd, а не .ps1 — он сам обходит политику
  выполнения и не закрывает окно.

  Если окно всё же закрылось мгновенно, откройте PowerShell в этой
  папке и выполните две строки — ошибка останется на экране:

     Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
     .\setup-windows.ps1


ПОСЛЕ УСТАНОВКИ: ТЕЛЕГРАМ

  Бот: @MegacamPulseControl_bot

  Найдите его, нажмите Start и скажите администратору — он свяжет ваш чат
  с учётной записью Taiga. Бот не имеет права писать первым: пока вы сами
  ему не напишете, рассылки не будет.

  Что приходит: утром — что на вас открыто и что зависло; вечером — что
  закрыли за день; сразу — когда на вас назначили карточку в BUG или ToDo.

  ТЕСТИРОВЩИКАМ: напишите боту  проекты?  — придёт список проектов
  кнопками. Отметьте свои и выберите режим: «сразу» для карточек,
  пришедших на проверку. Кит для этого не нужен, хватит бота.

  Уже назначенные карточки в уведомления не попадут: при подключении
  ставится отсечка, иначе прилетело бы два десятка сообщений разом.


ЧТО ЧИТАТЬ

  Taiga-for-managers.docx   инструкция для тех, кто ведёт задачи
  FOR-MANAGERS.md                         она же в текстовом виде
  FOR-DEVELOPERS.md                      дозорный, реестр, разбор тикетов по коду
  README.md                                 полное описание


ЧТО НУЖНО ЗАРАНЕЕ

  - установленный Claude Code
  - Python 3 (на macOS уже есть; на Windows ставится с python.org,
    при установке ОБЯЗАТЕЛЬНО отметить «Add Python to PATH»)
  - учётная запись в Taiga: логин и пароль


ЧЕГО СИСТЕМА НЕ ДЕЛАЕТ

  - не удаляет задачи: в Taiga это необратимо
  - не добавляет людей в проект без отдельной просьбы: уходит письмо
  - не правит код сам: разбор только читает и предлагает
  - не просит пароль в переписке: вход только в Терминале, вами


Исходники и обновления: https://github.com/Sigmatick/taiga-kit
